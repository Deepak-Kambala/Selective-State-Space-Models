Overview

Self-attention compares every token with every other token, so its cost grows quadratically with sequence length L. A state space model (SSM) instead carries a fixed-size hidden state h_t \in \mathbb{R}^N through the sequence and updates it with a linear recurrence, which costs time linear in L and constant memory per decoding step.

Earlier SSMs (S4 and relatives) used the same parameters at every position, so the model could not choose which tokens to keep or ignore. Mamba makes B, C and the step size \Delta functions of the input, which gives content-based selection. That change removes the global-convolution form S4 relied on for parallel training; Mamba replaces it with a hardware-aware parallel scan. Mamba-2 shows that a restricted selective SSM is equivalent to a form of linear attention.

This page works through three pieces: discretizing a continuous linear system, making it input-dependent, and parallelizing the resulting recurrence. The paper was accepted to the NeurIPS 2026 Education Track and ships with three notebooks and five exercises with solutions.

Linear recurrence

A discretized SSM maps an input sequence x_t to an output y_t through a hidden state:

h_t = \bar{A}\,h_{t-1} + \bar{B}\,x_t, \qquad y_t = C\,h_t

\bar A and \bar B are discretized versions of continuous-time matrices A and B with step size \Delta. With fixed parameters the model is linear-time and can be unrolled into a convolution, but it treats every position identically.

Discretization

Take the scalar system h'(t) = a\,h(t) + b\,x(t) and hold the input constant, x(t) = x_k, on [k\Delta, (k+1)\Delta) (zero-order hold). Solving the linear ODE from h(k\Delta) = h_k gives

h(t) = e^{a(t-k\Delta)}\,h_k + \frac{b\,x_k}{a}\left(e^{a(t-k\Delta)} - 1\right)

Evaluating at t = (k+1)\Delta:

h_{k+1} = \underbrace{e^{a\Delta}}_{\bar a}\,h_k + \underbrace{\frac{e^{a\Delta}-1}{a}\,b}_{\bar b}\,x_k

For a < 0, \bar a = e^{a\Delta} \in (0,1) for every \Delta > 0. A larger \Delta forgets the previous state faster; it cannot destabilize the system. Notebook 1 compares the discrete recurrence with RK4 numerical integration of the continuous system a=-0.8,\; b=1,\; \Delta=0.05,\; L=50 and reports the maximum absolute error.

Selectivity

In a selective SSM the input determines how the state is updated:

B_t = W_B\,x_t, \qquad C_t = W_C\,x_t, \qquad \Delta_t = \mathrm{softplus}(W_\Delta\,x_t)
\bar a_t = e^{\Delta_t A}, \qquad \bar b_t = \Delta_t B_t, \qquad h_t = \bar a_t \odot h_{t-1} + \bar b_t, \qquad y_t = C_t \cdot h_t

Here A is diagonal and negative, and the input enters the state through B_t. Mamba additionally multiplies by the channel input and uses a per-channel \Delta_t; the notebook uses one scalar \Delta_t per timestep, shared across state channels, and the first-order form \Delta B in place of the ZOH expression for \bar b.

When \Delta_t is large, \bar a_t is near 0: the state is overwritten by the current token. When \Delta_t is near 0, \bar a_t is near 1 and the current token barely changes the state. The model learns from content which tokens to retain and which to skip.

Because the coefficients now differ at every position, the recurrence is no longer a convolution with a fixed kernel, and S4's FFT-based training does not apply.

Notebook 2 trains this block on a synthetic selective-copying task. A few marker positions carry a signal value in [−1, 1] and all other positions carry small background noise; the target at every step is the most recent marker value. The notebook compares the block with a fixed-parameter SSM and plots the learned \Delta_t against marker positions.

Parallel scan

The recurrence h_t = \bar a_t h_{t-1} + \bar b_t looks sequential, but each step is an affine map, and composition of affine maps is associative. Represent step t as a pair (\bar a_t, \bar b_t) with

(a_1, b_1) \bullet (a_2, b_2) = (a_2 a_1,\; a_2 b_1 + b_2)

Any associative operator can be evaluated as a scan in logarithmic depth. Notebook 3 implements a doubling scan: in each round every element combines with the element 2^k positions earlier, for k=0,1,\dots until 2^k reaches the padded length. The initial state is folded in as one extra element, so n=L+1, and the sequence is padded to the next power of two. The number of rounds is

\text{rounds} = \lceil \log_2 n \rceil
Ln=L+1Padded nRoundsSequential steps

The doubling scan performs O(n \log n) combine operations against n for the sequential loop, but its depth is \lceil \log_2 n \rceil, which a GPU can exploit. Mamba uses a fused, work-efficient, hardware-aware implementation. On CPU, the speedup in Notebook 3 comes from fewer, larger vectorized operations rather than hardware parallelism.

Duality with attention

Mamba-2 introduces structured state space duality: restricting the transition to a scalar-times-identity form makes the SSM equal to a masked, linear-attention-like operator. The same layer can therefore be computed either as a recurrence or as a matrix multiplication, and the matrix form allows a faster algorithm on hardware optimized for matmuls.

Limits

A fixed-size state compresses the history. On tasks that need exact retrieval of arbitrary earlier tokens, such as copying or looking up a specific token far back in the context, attention's per-token cache has an advantage that a memory-only comparison does not show (Jelassi et al., 2024).

A running average of marker values is a case the Notebook 2 block cannot compute exactly. It would need \bar a_t = (n-1)/n after n markers, but \bar a_t is a function of x_t alone and the input carries no marker count. Exercise 3 works through this and the minimal architectural change that fixes it.

Learning objectives

  • State the recurrence of a discretized SSM and explain why a fixed-parameter SSM is linear-time but non-selective.
  • Explain what selectivity adds and why it prevents the convolutional form used in S4.
  • Implement a minimal selective-scan layer in PyTorch and run it on a toy task.
  • Compare a selective SSM with self-attention and a vanilla RNN on compute, memory and long-range recall.
  • Extend the notebook with a variant scan, such as a bidirectional scan, and evaluate it.
